# საინფორმაციო გვერდები — რა აკლია

ფუტერის ოთხი გვერდი: მიწოდების პირობები (`/delivery`), დაბრუნება და გარანტია
(`/returns`), კონფიდენციალურობა (`/privacy`), ხშირად დასმული კითხვები (`/faq`).
კოდი — `frontend/src/pages/Info/`.

ქვემოთ ჩამოთვლილი წინადადებები **საიტზე ახლა არ ჩანს** — არც ცარიელი ადგილით,
არც „მალე“-თი. სამი მათგანი მფლობელის ფაქტს ელოდება და ერთი ხაზით ივსება
`frontend/src/constants/index.js`-ში, `SHOP_FACTS`-ში: `null`-ის ნაცვლად
მნიშვნელობა ჩაწერეთ და წინადადება თავისით გამოჩნდება.

## 1. როგორ ბრუნდება პროდუქტი

- **გვერდი:** დაბრუნება და გარანტია — „როგორ დავაბრუნოთ“, მე-2 ნაბიჯი. ახლა
  სიაში ორი ნაბიჯია; ჩაწერის შემდეგ სამი იქნება.
- **მფლობელი აწვდის:** მთლიან წინადადებას — პროდუქტს კურიერი წაიღებს თუ
  მყიდველი გამოგზავნის, და ვინ აწყობს ამას.
- **ჩაწერა:** `returnPickup: 'კურიერი პროდუქტს თქვენი მისამართიდან წაიღებს',`

## 2. გარანტიის ვადა

- **გვერდი:** დაბრუნება და გარანტია — „დეფექტური პროდუქტი და გარანტია“.
- **წინადადება:** „პროდუქტზე ვრცელდება გარანტია, ვადით {X}.“
- **მფლობელი აწვდის:** ვადას.
- **ჩაწერა:** `warrantyPeriod: 'ერთი წელი',`
- **შენიშვნა:** პროდუქტის გვერდის „მიწოდება“ ტაბი წერს: „კონკრეტული
  ვადა მითითებულია მახასიათებლებში“ (`DELIVERY_INFO`), ანუ ვადა პროდუქტზეა
  დამოკიდებული. თუ ასეა, ერთი ვადის ნაცვლად წინადადებაც ამას უნდა ამბობდეს —
  გადაწყვიტეთ ჩაწერამდე.

## 3. ვინ ვართ

- **გვერდი:** კონფიდენციალურობა — სექცია „ვინ ვართ“ მთლიანად დამალულია.
- **მფლობელი აწვდის:** ბიზნესის სრულ დასახელებას, საიდენტიფიკაციო კოდს,
  იურიდიულ მისამართს.
- **ჩაწერა:** `legalEntity: { name: '…', idCode: '…', address: '…' },`
- **შენიშვნა:** ვინ ამუშავებს მონაცემებს — ეს არის ის, რისთვისაც ეს გვერდი
  არსებობს. სამიდან ეს შეავსეთ პირველი.

## 4. შეკვეთის სტატუსი სტუმრისთვის

- **გვერდი:** ხშირად დასმული კითხვები — „შეკვეთის სტატუსი სად ვნახო?“. პასუხი
  ახლა მხოლოდ რეგისტრირებულს მიმართავს; სტუმრის ნახევარი ამოღებულია.
- **რატომ:** სტუმარს საიტზე შეკვეთის მოსაძებნი გვერდი არ აქვს. backend-ს აქვს
  `POST /orders/lookup` (შეკვეთის ნომერი + checkout-ში მითითებული ტელეფონი),
  მაგრამ მაღაზია მას მხოლოდ იმ ბრაუზერში იყენებს, სადაც შეკვეთა გაფორმდა —
  დადასტურების გვერდის საჩვენებლად. სხვა მოწყობილობიდან ან ისტორიის
  გასუფთავების შემდეგ სტუმარი შეკვეთას ვეღარ ნახავს.
- **რა სჭირდება:** ერთ-ერთი —
  - ძებნის გვერდი (ფორმა: შეკვეთის ნომერი და ტელეფონი) და შემდეგ წინადადება
    `frontend/src/pages/Info/Faq.jsx`-ში — ეს ფუნქციაა, არა ერთი ხაზი;
  - ან მფლობელის გადაწყვეტილება, რომ სტუმარს ვწერთ „დაგვიკავშირდით შეკვეთის
    ნომრით“ — ეს ერთი ხაზია იმავე ფაილში.
